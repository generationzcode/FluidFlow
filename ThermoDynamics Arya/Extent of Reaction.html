Extent of Reaction

\[ \xi = \frac{N_i - N_{i0}}{v_i} \]

For example for reaction, \(C_2H_4 + \frac{1}{2}O_2 \ce{->} C_2H_4O\) \(\frac{r_{C_2H_4}}{v_{C_2H_4}} = \frac{r_{O_2}}{v_{O_2}} = \frac{r_{C_2H_4O}}{v_{C_2H_4O}}\) \[ G = \sum{x_i\bar G_i} = \sum \frac{N_i}{N^t}\bar G_i \] \[ \frac{dG^t}{d\xi} =\frac{d\sum N_i\bar G_i}{d\xi}= 0 \quad \quad \text{This is the condition for Chemcial Equilibrium} \]

\[ \sum v_i \bar G_i + \sum N_i\frac{d\bar G_i}{d\xi}\bigg|_{=0} = 0 \] \[ \therefore \sum v_i \bar G_i = 0 \] \[ \sum v_i \left[RT\ln \left(\frac{\bar f_i}{f_i}\right) + G_i\right] = 0 \] \[ \sum v_i \ln \left(\frac{\bar f_i}{f_i}\right) = - \sum \frac{v_iG_i}{RT} \] \[ \sum \ln \left(\frac{\bar f_i}{f_i}\right)^{v_i} = - \sum \frac{\Delta_{reaction}G}{RT} \] \[ \Pi\left(\frac{\bar f_i}{f_i}\right)^{v_i} = \exp \left\{\frac{-\Delta_{rxn}G}{RT}\right\} \] \[ \Pi\ a^{v_i} = K_a = \exp \left\{\frac{-\Delta_{rxn}G}{RT}\right\} \] \(K_a\)-> is the thermodynamic Chemical equilibrium Constant Differentiating it wrt temperature we get, \[ \frac{d(\ln K_a)}{dT} = \frac{d}{dT}\left[-\sum \frac{v_iG_i}{RT}\right] = -\sum \frac{H_i}{RT^2} = \frac{\Delta_{rxn} H}{RT^2} \] Hence the complete set of equations wrt to Standard State @\(25\degree C,\ 1bar\)

\[ \sum v_i \left[RT \ln\left(\frac{\bar f_i}{f_i\degree}\right) + G_i\degree \right] = 0 \] \[ \Pi \left(\frac{\bar f_i}{f_i\degree}\right) = \exp\left[\frac{-\Delta_{rxn}G_i\degree}{RT}\right] \]
