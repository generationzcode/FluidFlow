Testing NUll Hypothesis

Coefficient being “0” implies that that term has no effect on the result with corresponding confidence, else Reject value and we accept the NUll hypothesis

Think of the Null Hypothesis as an inate assumption we have pre analysis saying that a particular parameter has no effect on the result/value to be predicted

\[ \begin{align*} \text{Intercept}\quad & H_0: b_0=0 & H_a : b_0\neq 0 &\quad \text{if}\quad p_{value} < 0.001 \implies \text{Reject Null hypothesis with 99.9\% confidence, else Reject}\\ \text{Coeff of }x^1\quad & H_0: b_1=0 & H_a : b_1\neq 0 &\quad \text{if}\quad p_{value} < 0.001 \implies \text{Reject Null hypothesis with 99.9\% confidence, else Reject}\\ \text{Coeff of }x^2\quad & H_0: b_2=0 & H_a : b_2\neq 0 &\quad \text{if}\quad p_{value} < 0.001 \implies \text{Reject Null hypothesis with 99.9\% confidence, else Reject}\\ \text{Coeff of }x^3\quad & H_0: b_3=0 & H_a : b_3\neq 0 &\quad \text{if}\quad p_{value} < 0.001 \implies \text{Reject Null hypothesis with 99.9\% confidence, else Reject}\\ &\vdots&\\ \text{Coeff of }x^p\quad & H_0: b_p=0 & H_a : b_p\neq 0 &\quad \text{if}\quad p_{value} < 0.001 \implies \text{Reject Null hypothesis with 99.9\% confidence, else Reject}\\ \end{align*} \]

Model variation is give by: \[ \begin{align*} \sum(y_i - \bar y)^2 &= \sum[y_i - \hat y_i +\hat y_i - \bar y]^2\\ &= \sum^n_{i=1}[y_i - \hat y_i]^2 + \sum^n_{i=1}[\hat y_i - \bar y] +0\\ &= \text{ESS + MSS +0} \end{align*} \] \[ R^2 = \text{proportion of variation} = \frac{MSS}{TSS} = 1 - \frac{ESS}{TSS} \] where TSS = \(\sum[y_i - \bar y]^2\)

There is a drawback tot this, as this doesn’t give us any insight into model complexity and variation of data

The standard error give the 95% confidence interval for Expected y for given x

This shows that \(R^2\) is not a good measure/indicator of performance and model selection
It is Monotonically increasing function of model complexity

\(\because\) from numerical interpolation for a polynomial of degree \(w_n(x)\) that polynomial will pass through all the points \((x_i, y_i)\)
This will give the \(R^2\) term to be one and the curve will pass thorugh all the points

Some measure which will penalized the system if the model is getting “unnecessarily complex” The “Statisticians” addressed this issue by adjusting the \(R^2\) \[R^2_{\text{adj}} = 1 - \frac{\text{ESS}/(n-p-1)}{\text{TSS}/(n-1)}\] For the same data different people can come up with different Conclusions
