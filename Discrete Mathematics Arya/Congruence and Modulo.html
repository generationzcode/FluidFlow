Congruence Class

\(a,b \in \mathbb{Z}\) , if \(n \mid a- b\) a congruent to b modulo n \(a \equiv b\ \ (\mod n)\)

\(ac\equiv bc \mod n\) and \(\gcd(n,c)=1\) \(\implies a \equiv b \mod n\) if \(\gcd(n,c) = d\), then \(a \equiv b \mod(\frac{n}{d})\)

Linear Congruence Equation

\(ax \equiv b \mod n\) has a solution \(\iff \gcd(a,n)\mid b\) \(n\mid ax-b\) \(\mathbb{Z}_n^* = {\bar a \in \mathbb{Z_n} \mid \exists\ \ \ \bar b \ \ \mathbb{Z_n}(\bar a .\bar b = \bar 1)}\) if \(p\in \mathbb{N}\)

\(C_n:=\{a\in \mathbb{N}\mid \gcd{a,n}=1 \& 1\leq a\leq n\}\) \(C_n \subseteq \mathbb{N}\) if p is prime \(|C_p| = p-1\)

Euler’s \(\Phi\) Function

\(\phi:\mathbb{N}\to \mathbb{N}\) \(\phi(n) = {k\in\mathbb{N}\mid1\leq k\leq n,\gcd(k,n)=1}\) for \(p=\) prime number, \(\phi(p) = p-1\) \(k\in \mathbb{N}\ \ \ \ \ \phi(p^k) = p^{k-1}(p-1)\)
